# 群聊唤醒陪聊 (astrbot_plugin_wake_chatter)

一个 AstrBot 插件：机器人平时休眠，被群友用唤醒词唤醒后，会在一段时间内自主参与群聊讨论，时间结束自动休眠。

## 功能

- **唤醒词唤醒**：群友消息中包含任一唤醒词 → 机器人上线并回复该群友（可 @ 对方）
- **限时活跃**：默认活跃 5 分钟（可调），期间以可调概率"偶尔加入讨论"
- **重复唤醒刷新**：活跃期内再次检测到唤醒词 → 活跃时间重新计时，回复条数重置
- **休眠词休眠**：活跃期内检测到休眠词（如"别说话"）→ 立即休眠并发送告别语（可改/留空关闭）；休眠状态下休眠词不生效
- **自动休眠**：时间到自动休眠；回复条数用完后保持沉默直到倒计时结束
- **LLM 生成回复**：默认调用当前启用的 LLM，根据最近 20 条群聊上下文生成口语化回复；关闭后使用语料库随机回复
- **群号白名单**：可配置只在指定群生效

## 管理指令（仅管理员）

| 指令 | 说明 |
| --- | --- |
| `/陪聊状态` | 查看当前群活跃状态、剩余时间和本轮回复条数 |
| `/唤醒陪聊` | 手动唤醒当前群（不发欢迎语） |
| `/陪聊休眠` | 立即休眠当前群 |

## 配置项（WebUI → 插件配置）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| enabled | true | 插件总开关 |
| wake_words | ["小助手", ...] | 唤醒词列表 |
| sleep_words | ["别说话", ...] | 休眠词列表（活跃期内命中即立即休眠） |
| sleep_farewell | 好的～我溜了～ | 触发休眠词后的告别语，支持 {name} 占位符，留空不发 |
| active_minutes | 5 | 唤醒持续时间（分钟） |
| max_replies | 10 | 单次活跃期最大回复条数 |
| random_reply_chance | 0.15 | 随机插话概率（0~1） |
| reply_cooldown_seconds | 15 | 两次回复最小间隔（秒） |
| enabled_groups | [] | 生效群号（空=全部） |
| wake_reply_enabled | true | 被唤醒时是否回复唤醒者 |
| at_sender | true | 回复时是否 @ 对方 |
| use_llm | true | 用 LLM 生成回复 |
| llm_system_prompt | ... | LLM 人格设定 |
| wake_greeting | 我来啦～{name}... | 唤醒欢迎语模板 |
| wake_greetings / random_replies | [] | 自定义语料（留空用内置） |
| max_reply_length | 200 | 单条回复最大字数 |

## 安装

将本目录放入 `AstrBot/data/plugins/`（或通过 WebUI "从文件夹安装"），重载插件即可。无需额外 pip 依赖。

## 注意

- 使用 LLM 回复前请确保 AstrBot 已配置并启用至少一个 LLM Provider。
- 为避免与 AstrBot 自身的唤醒前缀/LLM 对话重复回复，建议本插件与 @机器人 触发的对话场景分开使用。
